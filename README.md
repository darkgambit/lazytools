# LazyTools 🔧🌙 — a website that earns while you sleep

**17 free, private, browser-based tools** (calculators, converters, generators) built as a static site.
Zero hosting cost, zero maintenance, monetized with ads + affiliate links. This is the "asset":
it stays up 24/7, ranks in Google, and earns from traffic.

**→ The step-by-step launch instructions live in [`CLAUDE-CODE-PROMPT.md`](CLAUDE-CODE-PROMPT.md) — paste that into Claude Code and it will deploy and monetize this whole thing for you.**

## Why this model (research summary)

- **Tool/calculator sites are the classic passive-income asset**: they answer a search query, need no
  login, cost ~$0 to run, and earn display-ad revenue per 1,000 pageviews (RPM).
  **Plan on $0.50–$3.00 RPM** for a new site on Adsterra with mixed-geo traffic. The $2.50–$12.50
  range you'll see quoted is AdSense money with premium US/UK finance traffic — do not budget on it.
  At $1.50 RPM: 33k pageviews/mo ≈ $50 · 167k ≈ $250 · 667k ≈ $1,000. See `PROGRESS.md` for the
  full earnings table and the 30-day plan.
- **Hosting is free forever**: Cloudflare Pages' free tier includes unlimited bandwidth and unlimited
  sites — a static site like this never outgrows it.
- **No payment-processor problem**: you never charge visitors. Ad networks pay YOU, and
  **Adsterra pays via crypto (BTC/USDT) or WebMoney/Paxum from as little as $5**, which works from
  Libya (where PayPal/Stripe aren't available). Google AdSense also lists Libya for publishers, and
  pays by wire to a bank account — slower but possible once you have real traffic.
- **It compounds**: every tool you add is a new page that can rank in Google and earn for years.
  The generator makes adding tools a 10-minute job (or a 2-minute job for Claude Code).

### Honest expectations 📉📈
This is a real asset, not a money printer:
- **Month 1–2:** near-zero traffic while Google indexes the site.
- **Month 3–6:** first real visitors if you keep adding tools (25+ tools is a good target).
- **Month 6–12:** typical outcome for sites that keep growing: $50–$500/mo. Many sites earn less;
  well-grown tool sites earn more. Traffic is the whole game — every tool page is a lottery ticket.

## Run it locally

```bash
cd lazytools
python3 -m http.server 8000     # open http://localhost:8000
```

## Rebuild after editing

```bash
python3 _generator/build.py
```

All pages, sitemap, robots.txt regenerate from `_generator/tools_core.py` + `tools_extra.py`.
`SITE_URL` and `CONTACT_EMAIL` are set at the top of `_generator/build.py`. **`SITE_URL` is
provisional** until the first Cloudflare Pages deploy assigns the real production hostname —
if it differs, change that one line, rebuild, and redeploy.

After adding tools, also re-run `python3 _generator/make_og.py` to refresh the social share card
(it bakes in the tool count, so it goes stale otherwise).

## How the money actually flows

1. **Ads (main income).** Create an [Adsterra](https://adsterra.com) publisher account → add your
   site → create 3 ad units → paste the codes into `assets/ads.js` → redeploy. Ads appear in the
   placeholder slots. Later, at ~10k visits/month, also apply to AdSense (better rates) and put its
   line in `ads.txt`.
2. **Affiliate links (bonus).** On the invoice/loan pages, link to accounting or finance tools with
   affiliate programs. Update `about.html` disclosures when you do.
3. **Growth loop.** More tools → more Google entries → more traffic → more revenue. Run the "grow"
   instruction in the Claude Code prompt weekly.

  crypto payments via NOWPayments links.
